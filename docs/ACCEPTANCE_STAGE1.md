## 第一次烧录后的顺序

1. **观察上电不运动。** 固件约 5 秒读取编码器，两路驱动始终禁用，不探测电机方向，不自动回零。上位机连接本身也不会使能。想记录完整自检日志，可先连接上位机再按控制板 RESET；若 USB 串口重新枚举，则重连读取当前状态。
2. **核对输入。** 点击“读取限位 / 编码器”。普通状态下两路 NC 未压应为 P0[3]=0、P0[4]=0，压下对应输入变成 1；NPN 未感应通常为 1、感应为 0，需要按实际传感器确认。nFAULT 正常为 1。磁场 `warning (angle valid)` 与编码器无效是不同状态。
3. **使能与低速点动。** 确认电流和活动空间后点击“使能”。此操作给驱动使能但不发运动脉冲，转子通电可能自行对齐。短按 arm1 左/右、arm2 左/右，确认实际方向与标签一致，松开能停。任何不一致先停止，不启动回零。
4. **先试停止，再完整回零。** 确认 arm1 的 d/右方向接近 P0[3]、arm2 的右方向接近 NPN；全部松开并等待静止。点击“开始回零”，在初始运动中点停止，确认停止后没有 `HOME OK`、两轴回零状态作废、心跳恢复也不自行继续。
5. **完整执行。** 重新使能，再启动回零。预期顺序：arm1 快碰 → 退开 → 慢碰 → 停稳 50 ms → 12 次有效编码器角度平均建立零点 → 反向移动 126°（22,400 微步）→ arm2 快碰 → 退开 → 慢碰 → 同样停稳并平均置零 → 向左展开约 162°（36,763 微步）→ 停稳和编码器检查。日志应出现各轴 `HOME ... averaged origin: samples=12 raw=... lsb`；raw 是电机单圈编码值，不是关节输出角。采样期间开关必须保持触发，编码器帧必须有效，否则停止。初始传感器已触发时会先释放并退开。先确认两轴展开全程有机械空间，再核对实际两杆是否共线；配置角度不能代替正式标定。
6. **确认结果。** 最后收到 `HOME OK`，且状态包含 `enabled=1 home=0 homed1=1 homed2=1`、参考有效。内部 arm1 保留开关原点，伸直位约相差 126°；arm2 从 NPN 原点展开后的内部命令计数为 -36,763。几何规划和参考遥测把最终伸直姿态记为 q1=q2=0，不应把内部开关计数混作规划角。默认两路电机侧编码器均参与到点检查，但不能据此宣称减速箱输出轴或笔尖准确到位。
7. **再回零一次。** 从伸直位重复执行，检查能重新返回开关并完成。初次通过后再做多次重复性测量，不把单次成功当作精度结论。

## 故障验收

在低速、可随时切断驱动且机构有支撑的条件下逐项测试，不用硬撞来制造故障：

| 项目 | 预期结果 |
|---|---|
| 窗口内 Space/Esc/停止按钮，包括伸直和慢碰阶段 | 整个流程中止，驱动禁用，参考作废；再次运动须显式使能并重建参考 |
| 上位机关闭或断开连接 | 请求停止并释放驱动，不自动恢复 |
| 窗口失焦或最小化 | 释放手动点动；已启动的回零、起点移动、上传及轨迹继续，回到窗口后点动要重新按键 |
| 主机心跳中断 | 固件按 250 ms 超时停止；实际反应时间需测量，不能用模拟结果代替 |
| P0[4] 全局限位触发 | 两轴停止、回零失败；清除输入后仍不自动使能 |
| 回零开关无法释放 | 释放阶段达到步数或时间上限后失败，不出现 `HOME OK` |
| 快碰/慢碰找不到开关 | 当前没有搜索步数或时间上限，不能期待搜索超时退出；应由操作者停止，其他心跳/编码器/限位保护仍在，不以碰撞来验证 |
| 任一路必需编码器角度无效 | 达到固件保护条件后停止并要求重新检查，不自动改为开环继续 |
| 驱动 nFAULT | 禁用两驱动并锁定故障；可能失去保持力，必须人工处理原因 |

操作者 STOP 和 nFAULT 会禁用驱动、失去保持力矩；通信、限位和编码器等保护停止通常保留电流，但全部作废参考。两者都不等同切断 VMOT 的实体急停；上电未使能时没有保持力。两路反馈均在电机侧，不能直接确认减速箱回差或笔尖偏移。详见 [STATE_MODEL.md](STATE_MODEL.md)。

## 反馈时提供这些信息

- 完整日志：上位机界面会显示 `%LOCALAPPDATA%\TwoLinkCommissioning\Logs` 下的具体文件路径。
- 停在哪一轴、哪一个阶段；开关手动触发前后的 `INPUTS`。
- 是否出现上电运动、使能后意外连续运动、停止无效、方向错误或 126°/162° 展开姿态不对。
- 条件允许时，拍一段从人工使能到成功/失败的机构视频。
