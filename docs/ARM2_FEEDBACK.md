# arm2 编码器反馈交付（2026-10-05）

固件 `stage2-v10-stop-latch`，协议 `proto=4`。当前交付默认 `ARM2_ENCODER_FEEDBACK=0`：arm2 编码器未固定时不参与启动、使能、回零、点动、PTP 或轨迹的反馈条件；arm2 按指令计数运行。人工伸直确认不要求 arm2 方向已识别。arm1 编码器仍必须有效。`STATE arm2fb=0` 标记此模式，TELEM/FAULT_SNAPSHOT 不输出 e2/err2，界面 arm2 实测/误差显示 —，记录对应字段留空。固定并验收 arm2 编码器后，将该宏设为 1 并重新构建；启用后仍保留丢反馈停机。

以下对齐项描述 `ARM2_ENCODER_FEEDBACK=1` 的实现；构建和 GPIO/串口仿真不能代替烧录后的控制验收。没有自动烧录、串口连接、使能或电机运动。

## 已实现

| 功能 | 两轴行为 |
|---|---|
| 实时采样 | 一次 38-clock SSI 菊花链事务，跳过两个 dummy bit；分别检查 18-bit 帧、奇偶校验、OCF/COF/LIN。INC=DEC=1 仍作为磁场范围警告报告 |
| 多圈位置 | 每轴独立累计 rotor LSB，限制样本间隔、跳变、指令与测量增量；无法恢复的圈数丢失锁存故障 |
| 故障保护 | 任一路断线、非法帧、计数不可信达到保护条件时停止两轴，禁止开环降级；保持原有保护停机/人为 STOP 的驱动器行为 |
| 方向与回零 | 两轴均在操作者请求的回零运动中识别编码器方向；双次触碰、12 点平均零点、伸直后的编码器验收 |
| 点动 | 各自记录跟随误差；超过 31 LSB 降速，达到 328 LSB 停止；稳定后以测得的位置为保持目标，超过 4 LSB 时每 12 ms 最多补一个微步 |
| PTP/轨迹 | 两轴均检查起点、运动中的跟随误差和最终误差；最终限值沿用 228 rotor LSB（arm1 约 0.501°，arm2 约 0.392°），不是精度保证 |
| 限位 | 指令 q1/q2/肘范围与双编码器模型角度均参与逐步方向判断；到边界可退回，不再向外发步 |
| 上位机 | q2 实测、q2 误差、两轴实时误差曲线、两轴 CSV/RMSE/峰值、双轴停机快照与故障前遥测、双轴离线回放 |
| 串口中断余量 | SSI 位内短暂屏蔽中断，位间允许 UART ISR；`irq_max_us` 记录最长屏蔽时间。GPIO 读取仍占用前台循环，实际高速脉冲时序需要验收 |

坐标必须区分：

```
q1_measured = e1 × 360 / (4096 × 40)
elbow_measured = e2 × 360 / (4096 × 51.06)
q2_measured = q1_measured + elbow_measured
```

e1/e2 是相对伸直参考、逆时针为正的累计电机轴 LSB。err/err2 是各自原始编码器方向的指令减测量。两轴均为 200 整步、1/8 微步；当前传动参数为 40:1 与 51.06:1。你的回零参数 126° / 161.5° 保留，分别对应 22,400 / 36,650 个微步。

## 使用限制

- 新固件需配套本次 `proto=4` 上位机；旧 `proto=2` 拒绝运动。实时遥测必须同时含 e2/err2，缺字段不能当作 arm2 反馈。历史文件仍可读，旧记录不会被补造 arm2 测量。
- 使能后两路方向均视为未知。先使用正常回零流程识别方向，此后可人工确认两杆伸直来建立人工参考。arm2 的静态方向还没有实机确认，代码没有猜测其极性；重新使能后需重新回零。
- 点动保持目标是停止并稳定后测得的位置，沿用 arm1 行为；它不会把已发生的微小点动终点误差补回原始指令终点。
- PTP/轨迹到点后沿用 arm1 行为，保留驱动器通电，但不自动启动点动的补步保持控制。检测故障会作废参考，不自动重试或恢复运动。
- 上位机 XY 由双电机轴反馈和连杆模型推算。它仍是估算；减速箱回差、输出轴弹性与笔尖偏移没有直接传感器测量。设备预览仍使用命令角，并明确标注来源。

## 离完整运动闭环还差什么

1. **连续跟踪控制律**：现有 PTP/轨迹发步仍由插补计划决定，编码器负责检查与保护。需要把每轴目标与实际位置误差持续转换成受限的脉冲速度/相位修正，包含加速度、反向、限位、饱和和大误差停机规则；不能只加一个无约束 PID。
2. **确定性执行与整定**：GPIO SSI 和发步共用前台循环，采样通常约 1 ms，忙时最多 5 ms 强制读取可能推迟脉冲；高速连续控制需要核实/改善采样及脉冲时间，再整定两轴增益、误差窗口、纠偏速度和到点保持。当前绘图/单点 2500 微步/秒上限（含 2486 的实测完成值）同样不能由离线逻辑测试证明。
3. **机械与坐标标定**：arm2 方向需在首次正常回零时验证；两个减速比、微步设置、磁铁固定/居中、126°/161.5° 伸直偏置及肘范围应按实物确认。最近诊断中的 INC=DEC=1 是磁场范围警告，角度可读不等于已完成磁场/精度标定。
4. **实机控制验收**：本版尚未烧录；两轴抗扰保持、丢步保护、组合运动误差和 UART/采样时序都尚无本版实测记录。不要求重复已取消的额外编码器独立性实验。
5. **输出轴/笔尖精度闭环**：若目标是消除减速箱回差或保证笔尖 XY 精度，仅电机轴反馈不足；还需要输出轴或末端测量及相应模型/控制。

因此，本次完成的是 arm2 与 arm1 的反馈、保护、点动保持和到点验收功能对齐。双轴连续轨迹伺服与实机精度验收仍是后续工作。
