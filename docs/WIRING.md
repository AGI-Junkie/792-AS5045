## 电气与固件要求

- `P1[0]` 是 NPN 开漏输入，必须以经确认的 `VDDIO` 上拉（确认可用时可使用 PSoC 内部上拉；否则外接 `4.7k–10kΩ`）。任何 GPIO 上都不得出现 12/24 V。
- `P0[4]`、`P0[3]` 配置为上拉数字输入。NC 回路正常时为低；压到限位或任一根限位线断开时为高。
- 传感器蓝线、两个开关 `COM`、电机驱动器和控制板通过 `J9 GND` 共地。不要把传感器电源正极直接接到 GPIO。
- 这三路是软件 GPIO 输入，不是硬件急停。需要人员安全的急停必须另设独立、常闭的驱动使能或电机供电回路。

## 上电前最小检查

1. 断电测两个微动开关：未压 `COM-NC` 导通；压下 `COM-NO` 导通。
2. 断电确认 NPN 黑线不与电源正极短接，粉线悬空。
3. 上电后先读取三路静态电平：两路未触发限位应为低，NPN 电平应与传感器状态一致；再逐个手动触发。

阶段一固件上电只做静态自检，两轴保持禁用。先用 `I` 读取并核对输入，再手动 `C` 使能、`R` 回零。P0[3] 是 arm1 的两次触碰回零开关；置零后 arm1 反向移动 127° 到伸直位，再由 P1[0] 完成 arm2 回零，然后向左展开约 163°（36,990 微步）。NPN 固定在 arm1 上，回零时两杆内夹角约 20°；展开角度需按实际姿态微调。P0[4] 在所有运动中始终是全局限位，触发后停止、作废回零状态，清除输入后仍须人工 `C` 重新使能，不自动恢复。

普通点动中，P0[3] 阻止 arm1 继续朝开关方向运动，NPN 阻止 arm2 继续朝传感器方向运动，允许反向退出。回零期间 Space/Esc 停止、断线超时、编码器失效和 nFAULT 都中止整个流程。软件停止保留驱动保持电流但不再发校正脉冲；nFAULT 会禁用驱动，机械臂可能失去保持力。详细验收步骤见 [STAGE1_ACCEPTANCE.md](STAGE1_ACCEPTANCE.md)。

`nFAULT` 高电平不能证明电机电源正常。DRV8825 数据手册将该脚低电平列为过温/过流指示；欠压章节说明 VM 过低会禁用并复位内部逻辑，不能据此保证失电时 nFAULT 必然拉低。`wiring.svg` 的旧 UVLO 备注不应作为供电判据，实际供电须测量电源端与载板端的 DC 电压。依据：[TI DRV8825 数据手册，6 与 8.3.7](https://www.ti.com/lit/ds/symlink/drv8825.pdf)。
