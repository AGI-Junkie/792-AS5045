## 当前为何不能点击执行

真实电流/温升、arm2 的 NPN 慢触碰后停止问题、伸直零偏与两轴机械范围尚未完成复测/标定。源码 `PTP_COMMISSIONED=0`，四个 PTP 范围参数也没有填入猜测值。

这个锁在固件中生效，不是只把上位机按钮变灰。即使直接发送合法 CRC 指令，当前 hex 也会拒绝。完成硬件确认后，才可填写 `PTP_MIN1_CD / PTP_MAX1_CD / PTP_MIN2_CD / PTP_MAX2_CD`（相对伸直位的百分之一度）、设置 `PTP_COMMISSIONED` 并重新编译验收。本次没有替用户解除锁；测试中的人工范围只存在于桌面模拟可执行文件。

编译检查要求范围完整、包含伸直零位；arm1 还保留原来的 ±90° 软件包络，arm2 限于 ±180° 表示范围。上述包络不是实际机构允许范围，必须用更窄的实测范围替代。

## 配置并验收后，单点的动作定义

1. 用户使能并完整回零，两轴展开完成后记录各自的命令步数作为伸直参考；原开关原点、127° / 163° 临时展开量不变。
2. 在 XY 页选择“单点”、输入 X/Y 并选择逆解分支。上位机计算关节角，量化为 0.01°，检查固件报告的关节范围，然后“低速移到此 XY 点”才可能有效。
3. 固件换算为各轴整数微步，以共享加减速时间基准和整数 DDA 分配脉冲；两个有位移的轴在同一主轴步事件完成目标。脉冲按轴依次发出，属于协调运动，不声称电气边沿严格同时。
4. 这是关节空间点到点动作，末端途中不保证直线。角度沿起止关节值单调变化并受固件范围限制，但未实现碰撞、线缆或障碍物规划。先验收短距离动作。
5. 上位机首版固定主轴上限 200 微步/s；固件协议允许 100～600 微步/s，主轴加速度 800 微步/s²。轨迹页的五个预览速度/加速度参数不用于该动作。尚未进行硬件调速验证。
6. 运动结束后停稳 50 ms，检查命令计数精确到达；arm1 还检查电机侧编码器与命令差不超过 16 LSB。arm2 无编码器，只能报告命令完成，不能称为实测笔尖到位。

任意停止、故障、重新使能或重新开始回零均使单点参考失效；手动点动也撤销单点参考，必须重新完整回零。正常单点完成后可继续下一个单点，不自动回原点。

## 保护与通信

- 指令必须完整、CRC 正确、序号递增、参考 epoch 匹配；重复的已接受指令不重新执行。停止后旧 epoch 的指令无法恢复运动。
- 拒绝未使能、未完整回零、参考/方向未知、驱动/编码器异常、按键未释放、回零或单点忙、范围或速度无效等状态。
- 在单点运动和停稳确认中继续检查 250 ms 心跳、全局限位、两个回零输入、编码器跟随误差和 600 秒总超时。触发任一保护即进入既有停止流程；普通停止仍保持电流，nFAULT 禁用驱动。
- 无追赶脉冲突发。编码器读取和日志发送继续服从主轴脉冲时隙。单点期间拒绝回零；如果收到点动按键则中止单点。
- 窗口失焦、总停止或通信故障清空待发指令；上位机等不到接受状态 3 秒就停止，不自动重试。UI 卡住时心跳同时停下，由下位机超时停止。

现有串口是 115200 的轮询软件 UART，仅适合这次低速、短指令单点接入。整条轨迹流、队列和稳定的连续插补尚未实现；不能把离线 CSV 当作可下发的轨迹。

### 单点帧 v1

起始字节 `D1`，结束字节 `D3`。中间 17 个原始字节，各拆为低 nibble 在前、高 nibble 在后的两个奇数线上字节：`81 | (low<<1)`，`A1 | (high<<1)`。每个线上字节发三份；重复份幂等，使用 1.3 ms 间隔避开 1 ms 编码器读取周期。上位机每 40 ms 最多发送八个逻辑字节，并继续发送原有心跳。

| 原始偏移 | 字段 | 编码 |
|---|---|---|
| 0 | 帧版本 | 01 |
| 1～4 | sequence | uint32 小端，非零 |
| 5～8 | reference epoch | uint32 小端 |
| 9～10 | q1 | int16 小端，百分之一度，左转/逆时针为正 |
| 11～12 | q2 | int16 小端，百分之一度，相对 arm1 向前延长线 |
| 13～14 | 主轴速率上限 | uint16 小端，微步/s |
| 15～16 | CRC16-CCITT | 初值 FFFF、多项式 1021，覆盖前 15 字节，小端 |

完整帧共 36 个逻辑线上字节，含三份重复为 108 字节。接收过程中允许心跳穿插，STOP 永远优先；噪声不能当作 C/R 命令执行，最终仍需严格长度和 CRC。字节间 250 ms、总帧 2 秒超时均丢弃。帧时序模拟通过不能证明真实 USB/串口链路可靠性。

状态行例：

```text
STATE fw=stage2-v1 enabled=1 home=0 homed1=1 homed2=1 fault=0 enc=1 dir=1
PTP_STATE lock=1 ref=1 active=0 epoch=2 seq=0 min1=0 max1=0 min2=0 max2=0
```

`active=0/1/2` 分别为空闲、运动、停稳检查。`lock=1` 时上位机不开放执行。范围采用百分之一度；这里的零是未配置，不是已验证的零范围。
