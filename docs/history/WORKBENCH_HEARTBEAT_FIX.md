本页记录历史低速复测交付 `deliverables/stage2-workbench-v6-home-slow`，其上位机标题含“v6 回零心跳修复”，失焦会取消自动动作。该包的回零降速由 `firmware.hex` 实现，只换上位机不会改变速度；以下复测步骤和数据针对这个历史版本。

后台运行修复包 `deliverables/stage2-workbench-v6-background` 保留。当前串口与确认反馈包见 [WORKBENCH_UART_RECOVERY.md](WORKBENCH_UART_RECOVERY.md)：切窗或最小化不会取消回零、起点移动、上传及轨迹执行；失焦仅释放手动点动，回焦不会自动恢复点动。关闭、断连、真实超时和主动停止仍会结束动作。Space / Esc 仅在上位机窗口有焦点时有效，不是系统全局快捷键。参数及可选 arm2 提速复测见 [WORKBENCH_PARAMETERS.md](WORKBENCH_PARAMETERS.md)。

## 新的跟随报警与复测

本机日志 `stage1-20260927-185355-293.log` 记录两次 arm1 快碰报警：18:54:06 的误差为 332 LSB、心跳年龄为 34 ms；18:54:27 的误差为 329 LSB、心跳年龄为 17 ms。均在第一次触碰开关前停止，arm2 尚未运动。方向探测 16 微步得到 43 / 41 LSB，接近配置值 40.96 LSB。停止后仍有明显偏差，因此不能只用心跳超时或采样延迟解释。操作者反馈没有明显抖动、异响或机械阻挡；日志本身不能确定驱动跟随不足和编码器安装问题中的具体原因。

旧回零快碰为 2000 微步/秒，高于已能正常点动的 arm1 800、arm2 600 上限。本包将快碰、释放和退开降至 600，arm1 伸直为 800，arm2 伸直为 600 微步/秒；二次触碰 400、加速度 4000、250 ms 心跳保护、328 LSB 跟随保护及 120 秒阶段超时均保留。

该历史包烧录后连接、读取状态、松开所有点动键，再“使能 / 重新检查”和“开始回零”。原始日志应出现 `HOME arm1 phase=3 fast touch rate=600 usteps/s`，可据此核实低速固件已生效。回零会比此前高速版慢：arm1 伸直匀速部分约 28.2 秒，arm2 约 61.7 秒，实际含加减速和调度时间。这个历史上位机要求保持窗口前台；当前后台运行版已取消自动动作的该要求。复测时仍应观察实物，异常时回到上位机按 Space / Esc 或点击“总停止”；报警后不要连续重试或把当前位置直接确认为伸直。

实际 C 模拟先在旧速度下复现跟随报警，降低速度后同一限速电机模型完成回零；另一个已确认方向后模拟停转的用例仍触发跟随报警并停止脉冲。230 个实际 C 用例、线段和矩形执行模拟、Creator 固件构建和完整上位机自测通过。模拟的限速电机是诊断假设，不是实物能力测量。未连接串口、烧录或验证真实运动。若低速仍报警，应继续核查驱动、电机及编码器安装，不提高报警阈值来掩盖偏差。

## 先看实物是否能小幅移动

1. 抬笔，确认所选关节有少量无障碍行程。连接 COM8，等待“在线 · v6 硬件串口”。
2. 在“设备 / 回零”页读取限位 / 编码器，确认输入正常，松开所有点动键，再点击“使能 / 重新检查”。
3. 等待“已使能”，只按住一个屏幕点动按钮约 0.5 秒后松开。arm1 命令转角约 2°，以实物为准。手动点动需窗口激活，确认松开即停；异常使用本窗口 Space / Esc 或“总停止”。
4. 短点动不要求先建立零位，但未建立参考时并不具备完整的参考相关软件保护。不要长按来寻找机械边界。

画圆前要重新建立真实零位；不能把刚才移动后的弯折姿态确认为伸直。驱动保持通电时不要硬掰关节。从正确伸直零位低速接近小圆起点约需 33 秒，实际略长；到位后才能“上传并执行图形”。

## 修复与验证

2026-09-27 现场日志记录心跳发送间隔 364 / 444 ms；固件在 key_age_ms=251 时停止。旧心跳和串口解析、界面处理共用 Background 优先级计时器。

当时心跳改用独立的 UI Input 优先级计时器，与停止、松键按同一优先级排队。接收处理仍在原来的计时器中。该历史包保留固件 250 ms 保护、反馈过期断开、失焦停止和重新确认零位流程。当前后台运行版将失焦处理改为仅释放手动点动，自动动作继续；通信保护仍保留，没有无条件后台续发心跳。

实机使用首版心跳修复后，2026-09-27 18:47:32 / 18:48:05 两次回零仍在约 2 秒时中断，心跳间隔为 296 / 369 ms。进一步使用真实显示窗口、WPF 调度器和回零状态接收处理进行离线回放，复现 337.8 ms 心跳间隔，接收回调仅 16.6 ms。移除未知进度的循环动画后，同一回放最大心跳间隔降至 67.3 ms。

回零、起点接近及等待确认用现有状态文字显示；未知进度时隐藏进度条。上传和绘制保留已知百分比进度。停止和输入处理的调度优先级、固件保护均保留。

离线回归使用真实 WPF 调度器和生产计时器：旧版在连续的短输入任务下心跳间隔约 712 ms；修复后须低于 250 ms。另有 4 秒真实显示窗口的回零回放，覆盖循环动画导致的延迟。测试同时检查 UI / 输入阻塞时停止心跳，以及设备状态过期后关闭两个计时器。实测结果见交付目录 `heartbeat-tests.txt`。

完整上位机自测与固件的 PTP / 轨迹 / 人工参考心跳超时模拟通过。未连接串口、烧录或驱动机械臂；现场是否还存在单次渲染或磁盘阻塞，须用新版实机复测确认。
