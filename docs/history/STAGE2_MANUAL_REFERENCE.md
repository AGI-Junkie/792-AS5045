# 人工建立坐标参考：不强制回零

> **历史记录**：记录当时那次交付的改动和验证，可能与当前源码不一致（版本目录、固件标识、坐标约定都已变）。当前说明见 [README](../../README.md)、[协议](../PROTOCOL.md)、[状态模型](../STATE_MODEL.md)；以源码为准。

新版 `stage2-v3` 固件和 `deliverables/stage2-manual-reference/host` 上位机增加 **“人工确认：当前位置为伸直零位”**。开关回零仍可选择，试验不必执行它。

1. 用 PSoC Creator 打开当前 `DRV8825.cywrk`，Build/Program；也可烧录本交付的 `firmware.hex`。旧 stage2-v2 不支持人工参考指令。
2. 人工把两杆沿选定的 +X 方向摆成伸直姿态。软件将这一姿态定义为 q1=0、q2=0，末端为 (356.38, 0) mm。不要把弯折姿态当作伸直零位；带保持电流时不要强扳关节。
3. 连接新版上位机，点击“使能 / 重新检查”，松开所有点动按键并等两轴静止，再点击 **“人工确认：当前位置为伸直零位”**。
4. 出现 `MANUAL REF OK`、坐标参考“已建立”后，可直接“低速移到轨迹起点 → 上传并执行图形”。默认圆心 (340,0) mm、半径 5 mm。人工确认指令自身不发 STEP、不启动回零、不自动拉直机构。

人工坐标和开关回零都可使已有 `homed1/homed2/ref` 状态位有效；本版界面统一显示“坐标参考”，不把人工确认报告为完成开关回零。日志明确记录人工声明。

停止、失焦、断线或点动导致参考失效后，可以重新摆直并人工确认，不必找开关。软件关节范围仍为 q1 ±30°、q2 ±60°；它们是临时软件限制。当前用户此前的 (280,0)、半径 50 mm 圆超出整段范围，人工参考不会扩大范围。

固件复用带 CRC/sequence/epoch 的 17 字节协议，操作类型 `05`，q1/q2/最后 uint16 都必须为 0。只在已使能、静止、空闲心跳、有效编码器、所有传感器无触发且不在上传/运动时接受。接受后更新 epoch、清除旧缓存、将当前两轴命令计数记为原点，并同步 arm1 编码器命令基线。重复同一请求只回复状态，不重复置零；此前 epoch 的目标指令失效。

人工模式不做方向探测运动。arm1 编码器极性采用这台设备 2026-09-24 的真实回零日志确认值 `increase DIR=1`，保留配置项 `MANUAL_ENC_INC_DIR`；换接线或机构后需重新校准它。限位、nFAULT、编码器异常/跟随误差、心跳、速度和停止保护保留。

验证包括：人工确认零脉冲、非零计数原点、确认后 PTP、停止后再次人工确认、旧 epoch/重复/坏 CRC/无使能/运动中/上传中/传感器/编码器/心跳拒绝，以及完整“人工摆直 → 确认 → 接近起点 → 上传小圆 → 执行”模拟。未烧录或实机运行。
