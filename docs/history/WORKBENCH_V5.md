# Two-Link Studio v5：软件交付与实机验收

本版完成当前硬件配置下的软件流程：连接 / 自检信息 → 人工使能 → 人工伸直零位或开关回零 → 图形检查 → 低速接近起点 → 整条上传确认 → 双轴绘制 → 显示反馈并自动保存实验。

固件标识 **stage2-v5**。请同时使用本目录的 `firmware.hex` 与完整 `host` 文件夹；旧上位机不识别 v5。当前源工程 `DRV8825.cywrk` 可以在 PSoC Creator 4.4 Build / Program。软件编译和模拟检查已经完成；烧录与实际机械臂验证由使用者完成。

## 第一次运行

1. 关闭旧版上位机。烧录 `firmware.hex`，或在 Creator 中 Build / Program 当前工程。
2. 运行 `host/TwoLinkCommissioning.exe`（需 .NET 10 Desktop Runtime，当前电脑已具备）。连接实际 KitProg COM 口，顶部应显示“在线 · 固件 v5”。连接不自动使能或运动。
3. 使能。人工把两杆沿 +X 摆直，再点击“人工确认当前位置为伸直零位”；也可以选择开关回零。人工确认不发 STEP 脉冲；不要把弯折位置确认为伸直。
4. 点击“载入小圆示例”：L1=180 mm、L2=176.38 mm，圆心 (340,0) mm，半径 5 mm。先检查界面提示。
5. **抬笔**，点击“低速移到轨迹起点”。等待角度反馈和到位检查；主轴速度仍为 200 微步/s，所以接近起点需要一段时间。
6. 显示“已到当前轨迹起点”后，人工落笔，点击“上传并执行图形”。上传时不运动，显示点数与估计剩余时间；完整上传后自动执行。上传耗时不包含在绘制时长内。
7. 完成后底部显示实验结果，点击“打开实验数据目录”查看文件。运行中参数不可编辑，原始日志仍可选中并用 Ctrl+C 复制。

停止按钮固定在右上角，Space / Esc 也可停止。运动、上传、回零或等待控制确认期间切换到其他窗口会停止；静止时可以打开参数文件或数据目录。停止后不能续跑旧路径：重新使能、人工摆直确认或回零，再接近起点。

## 防呆与恢复

| 情况 | 软件行为 / 下一步 |
|---|---|
| 未连接、旧版固件、反馈过期、未建立参考 | 显示原因和下一步；不发送运动包。完整绘制的当前位置确认需要 v5。 |
| 重复点击、上传 / 运动中修改参数 | 首次请求立即锁住互斥操作；修改参数不会偷换正在执行的计划。 |
| 尚未到达当前计划的起点 | 上位机根据同一参考和序号的新鲜步数反馈检查，固件在上传和启动时再次检查；不自动接近。 |
| 改了圆心、半径、分支、尺寸或范围 | 重建预览并重新核对起点。不能把上一条轨迹的到位状态用于新轨迹。 |
| 目标或整条轨迹越界 | 说明目标 / 点号及允许范围。规划范围只能进一步收紧，不能扩大固件限制。 |
| 损坏 / 不完整指令包 | 记录 `PTP RX dropped`；同一序号、epoch、数据最多发送 3 次，仍沿用 3 秒总期限。重复包只确认，不重复执行。 |
| 使能 / 回零指令未收到确认 | 3 秒后停止并给出恢复提示，不让界面无限停在“等待”。 |
| 状态格式异常、参考代次改变、反馈超时、真实拒绝 | 取消待发指令并停止，不自动恢复。错误给出中文解释，原始原因保留在日志。 |
| 限位、NPN、驱动故障、编码器失效或跟随误差 | 由固件持续检查并停止；250 ms 心跳保护保留。上位机显示当前输入状态。 |
| 数据目录不可写 / 写入失败 | 开始记录失败时不启动实验；运行时写入失败会请求停止。已写入的反馈 CSV 保留，摘要失败会提示。 |
| 想保留参数 | 使用“保存参数 / 载入参数”。文件只保存规划参数，不保存使能、零位有效性或自动启动状态。 |

## 反馈的含义

- **arm1 命令角度**：相对本次零位的微步命令换算角度。
- **arm1 编码器角度**：电机侧编码器相对本次参考的读数，按名义 40:1 减速比换算；不是输出轴独立测量，不能测出减速箱回差。
- **arm1 偏差 / RMSE / 峰值**：编码器换算角度减命令角度。约 2 Hz 加状态变化采样，只适合低速观察，不能代替高速跟踪精度测试。摘要统计排除上传阶段。
- **arm2**：只有命令步数，没有编码器。界面紫圈为两轴命令计算的位置；不是实测笔尖位置。
- **XY**：CSV 同时给出纯命令模型估算，以及 arm1 编码器 + arm2 命令的混合估算。没有真实笔尖 XY 误差；相关实测列留空，不填假零。
- **参考来源**：明确区分人工伸直零位与开关回零。日志中的 homed 字段为历史协议的“参考已建立”标志，不能把人工确认当作触碰开关成功。

## 文件

原始会话日志仍在 `%LOCALAPPDATA%\TwoLinkCommissioning\Logs`。

每次单点或绘图实验在 `%LOCALAPPDATA%\TwoLinkCommissioning\Experiments` 下创建独立目录：

| 文件 | 内容 |
|---|---|
| `metadata.json` | 连杆尺寸、图形 / 速度参数、参考来源、epoch / sequence、测量边界。 |
| `plan.csv` | 实际下发的量化节点和累计计划时间。单点文件只列目标，不虚构完整 PTP 时间曲线。 |
| `feedback.csv` | 主机 UTC、设备毫秒、参考 / 序号、阶段、命令角、arm1 编码器、偏差、XY 估算、输入与丢包计数。 |
| `summary.json` | 完成 / 中止原因、采样数、运动样本数、arm1 RMSE 与峰值。缺少此文件说明进程在最终保存前中断，不能当作完整实验。 |

交付的 `preview.csv` / `*.execution.bin` 是离线检查数据，不是机器实验记录。`workbench*.png` 使用模拟数据展示界面，不代表实机已通过。

## 实机验收顺序

依次记录结果；每一步都应能从界面与日志判断成功或失败。

1. 无运动准备：确认 v5、输入释放、编码器正常；使能及人工零位收到确认，角度从本次参考计算。
2. 小幅点动与软件停止：方向正确，松开能停；Space / Esc、运动时窗口失焦均能停。停止后旧参考不能直接续跑。
3. 小圆起点接近：确认实际旋转方向与角度变化一致，出现 `PTP accepted`，最终 active=0，并开放该计划的绘制按钮。
4. 小圆上传与绘制：上传期间静止；全部节点确认后才绘制；完成后生成实验三类数据和摘要。
5. 检查参考丢失、起点不符、越界参数的提示；这些情况应拒绝运动。再检查直线与矩形。
6. 正式测定机械范围、伸直零偏、尺寸、驱动电流与温升、回差和画线精度，再据实调整参数。现有 arm1 127° / arm2 163° 展开量及额外 2° / 3° 仍是先前目测修正。

当前 q1 ±30° / q2 ±60° 是用户授权开放的临时软件限制，不是实测机械范围。没有笔升降执行器接口，所以抬落笔仍由人工完成。开关 / 软件停止不能替代独立实体急停。

## 可复现的软件验证

在工程目录运行 `powershell -ExecutionPolicy Bypass -File .\build-release.ps1`。脚本只编译、做离线测试、生成文件；不打开串口、不烧录、不驱动机械臂。可以用 `-OutputDirectory deliverables\my-check` 指定工程内的新交付目录。

验证包括 Creator 固件构建、WPF 自测、两种窗口尺寸截图、实际固件 C 的锁定 / 协议 / 交付参数模拟，以及圆、直线、矩形在“开关回零 / 人工参考”两条路径下的逐段执行检查。详情看 `BUILD_REPORT.txt` 和各测试日志。软件检查不证明真实 USB 时序、负载、电流、线缆与传感器机械安装已经正确。
